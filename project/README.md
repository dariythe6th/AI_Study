# MoodTune — AI Music Curation Service

**Итоговый сквозной проект по курсу «Инженерия Искусственного Интеллекта»**


## 1. Паспорт проекта

- **Название проекта:** MoodTune — AI Music Curation Service
- **Автор:** Родионова Дарья Никитична
- **Группа:** ИКБО-22-23
- **Контакт:** dunya.rodionova@gmail.com
- **Краткое описание:**

Сервис, который по текстовому описанию настроения, ситуации или активности (например, «rainy coffee shop morning» или «energetic workout») подбирает персонализированный плейлист с реальными треками.

**Основные технологии:**
- Семантический поиск на базе Sentence-Transformers (`all-MiniLM-L6-v2`)
- Векторная база ChromaDB
- FastAPI + современная архитектура (`src/`)
- Авторизация пользователей и избранное
- Красивый фронтенд (HTML + JS)

Проект демонстрирует полный цикл инженерии ИИ: от работы с данными и экспериментов до production-ready API-сервиса.


## 2. Структура проекта

Проект организован по рекомендациям курса:

- `data/` — демонстрационный датасет высокопопулярных треков Spotify
- `notebooks/` — EDA и сравнение моделей (`01_eda.ipynb`, `02_baseline_models.ipynb`)
- `src/` — чистая модульная архитектура (data, models, service)
- `api/` — FastAPI приложение
- `configs/` — конфигурация через `pydantic-settings`
- `tests/` — базовые тесты
- `Dockerfile` + `docker-compose.yml` — контейнеризация


## 3. Требования и установка

### 3.1. Требования
- Python ≥ 3.10
- ~2–3 ГБ свободного места (для модели и ChromaDB)

### 3.2. Установка

```bash
cd project

# Создание окружения (рекомендуется)
python -m venv .venv
source .venv/bin/activate    # Linux / macOS
# .venv\Scripts\activate     # Windows

pip install --upgrade pip
pip install -r requirements.txt
```


## 4. Как запустить проект

### 4.1. Через Docker (рекомендуемый способ)

```bash
docker compose up --build
```

Сервис будет доступен по адресу: **http://localhost:8000**

### 4.2. Локально

```bash
# Активировать окружение
source .venv/bin/activate

# Запуск API
python -m api.main
```

**Ключевые эндпоинты:**
- `GET /health` — проверка работоспособности
- `POST /recommend` — основная рекомендация (требует авторизацию)
- `/auth/register`, `/auth/login` — регистрация и вход

**Пример запроса через curl:**
```bash
curl -X POST "http://localhost:8000/recommend" \
  -H "Content-Type: application/json" \
  -d '{"text": "chill rainy day lo-fi", "limit": 8}'
```

**Фронтенд:** просто откройте файл `index.html` в браузере (он обращается к `http://localhost:8000`).


## 5. Данные

- **Источник:** Открытый датасет высокопопулярных треков Spotify (high_popularity_spotify_data.csv)
- **Размер:** ~ несколько тысяч треков с аудио-фичам (energy, danceability, valence и т.д.)
- **Расположение:** `data/high_popularity_spotify_data.csv`
- Данные очищены и подготовлены в `src/data/loader.py`


## 6. Эксперименты и ноутбуки

В папке `notebooks/`:

- `01_eda.ipynb` — разведочный анализ данных, визуализации, выводы
- `02_baseline_models.ipynb` — сравнение TF-IDF vs Sentence-Transformers

**Вывод экспериментов:** Sentence-Transformers значительно превосходит классический TF-IDF по качеству семантического поиска.

## 8. Ограничения и дальнейшая работа

**Текущие ограничения:**
- Нет реального аудио-превью треков (только ссылки на поиск в Spotify/Apple Music).
- Простая rule-based система определения настроения (можно улучшить LLM).
- Базовая авторизация (JWT + SQLite).

**Планы на развитие:**
- Интеграция с реальным Spotify API.
- Добавление RAG поверх описаний треков + LLM для объяснений.
- MLflow для трекинга экспериментов.
- Деплой на облако (Render / Railway / Yandex Cloud).
- Пользовательская история запросов и персонализация.
